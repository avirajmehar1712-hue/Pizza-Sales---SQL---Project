## 🍕 Pizza Sales — SQL & Excel Analytics Project

This project analyzes a pizza shop's sales data to extract key performance insights using **SQL queries** and also includes an **interactive Excel dashboard** built on the same dataset.

---

## 📊 Features
- **SQL KPIs**:  
  - Total revenue  
  - Average order value  
  - Total pizzas sold  
  - Total orders placed  
  - Average pizzas per order  

- **Trends Analysis**:  
  - Daily sales trends  
  - Hourly order distribution  

- **Category & Size Analysis**:  
  - Sales by pizza category  
  - Sales by pizza size  

- **Product Insights**:  
  - Top 5 best-selling pizzas  
  - Bottom 5 least-selling pizzas  

- **Excel Dashboard**:  
  - Visualized the same KPIs and trends using Excel charts & slicers  
  - Provides an easy-to-use interactive dashboard for non-SQL users  

---

## ⚙️ How to Load Data
You can either:
1. **Use an `INSERT` SQL script** to populate the database, or  
2. **Directly import the provided Excel file** into SQL Server using:
   - Import Wizard, or  
   - `BULK INSERT` (after saving as CSV).
